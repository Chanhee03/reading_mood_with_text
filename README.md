# jev

입력한 문장에서 감정을 판독하는 CLI 도구입니다. OpenAI API(`gpt-4.1`, Structured Outputs)로 [플루치크(Plutchik)의 감정 이론](https://namu.wiki/w/%EB%A1%9C%EB%B2%84%ED%8A%B8%20%ED%94%8C%EB%A3%A8%EC%B9%98%ED%81%AC)에 따라 8가지 기본 감정 중 주 감정과 부 감정, 강도, 신뢰도를 분석하고, 감정별 해양이 이미지와 함께 결과를 보여줍니다. 주 감정과 부 감정의 조합으로 만들어지는 합성 감정은 이미지 없이 텍스트로 보여줍니다. 부정적인 감정이 강하게 나타나면 대응 방법에 대한 코멘트도 함께 보여줍니다.

## 감성사전 근거 단어

입력 문장을 형태소 분석(kiwipiepy)해 감성사전(`data/sentiment.json`)에 있는 단어를 찾고, 단어별 극성(1 매우 부정 ~ 7 매우 긍정)과 뜻을 참고 자료로 함께 모델에 넘깁니다. 모델은 그중 실제로 화자의 감정을 드러내는 단어만 근거 단어(`evidence_words`)로 고른 뒤 감정을 판단합니다. 부정어, 반어, 대상 묘사처럼 사전 극성과 다르게 쓰인 단어는 근거에서 뺍니다. 평가에서 가장 정확했던 구성입니다 (아래 [평가](#평가) 참고).

- 감성사전은 교수님 연구 자료라 저장소에 없습니다. `감성사전.xlsx`를 받아 `python build_sentiment.py`로 `data/sentiment.json`을 만듭니다.
- `data/sentiment.json`이 없으면 감성사전 없이 판독하고, 근거 단어도 표시하지 않습니다.
- 감성사전에서 찾은 단어가 있을 때만 결과에 `근거 단어:` 줄이 나옵니다 (예: "친구가 약속을 또 어겨서 너무 짜증나고 실망스러워" → `근거 단어: 어기다, 짜증, 실망`).

## 신조어 처리

입력 문장에 신조어가 있으면 [KoCulture-Dialogues](https://huggingface.co/datasets/huggingface-KREW/KoCulture-Dialogues) 데이터셋에서 그 신조어가 쓰인 예시 대화를 찾아, 참고 자료로 함께 모델에 넘깁니다. 모델이 신조어의 뜻을 문맥으로 파악해 감정을 더 정확히 판독하도록 하기 위한 것입니다. 문장 자체를 표준어로 바꾸지는 않습니다.

- 사전: `data/neologisms.json` (신조어 354개, 단어당 예시 대화 최대 2개)
- 탐지: 입력 문장에 신조어가 그대로 들어 있는지 확인합니다. 한 글자 신조어(`갓`, `각` 등)는 일반 단어와 구분이 안 돼 제외합니다.
- 한계: `사이다`, `고구마`처럼 일반 단어와 같은 신조어는 원래 뜻으로 쓰여도 신조어로 잡힙니다. `~에 진심인 편`처럼 틀 형태인 신조어는 탐지되지 않습니다.

신조어가 탐지되면 모델에는 입력 문장 대신 아래 형식의 텍스트가 user 메시지로 넘어갑니다 (`main.py`의 `build_state`). 신조어가 없으면 입력 문장만 그대로 넘어갑니다.

```
[분석할 문장]
요즘 갓생 사는 게 내 추구미임

[참고: 위 문장에 쓰인 신조어의 용례. 감정 판단 대상이 아니며 신조어의 뜻을 이해하는 데만 사용]
- 추구미: "<예시 대화 1 질문>" / "<예시 대화 1 답변>"
- 추구미: "<예시 대화 2 질문>" / "<예시 대화 2 답변>"
- 갓생: "<예시 대화 1 질문>" / "<예시 대화 1 답변>"
- 갓생: "<예시 대화 2 질문>" / "<예시 대화 2 답변>"
```

예시 대화에도 감정이 담겨 있어 판독에 영향을 줄 수 있으므로, 감정 판단 대상이 아니라는 안내를 함께 넣습니다.

사전을 다시 만들려면:

```bash
pip install pyarrow
python build_neologisms.py
```

## 출력 예시

```
입력: 오랜만에 옛날 사진을 보니까 그때가 그립다

[분석 완료]
<슬픔 이미지>
주 감정: 슬픔
<기쁨 이미지>
부 감정: 기쁨
합성 감정: 씁쓸함 (슬픔 + 기쁨)
강도:   🟧🟧🟧🟧🟧🟧⬜⬜⬜ (6/9)
신뢰도: 87%
```

주 감정이 부정적인 감정(공포, 슬픔, 혐오, 분노)이고 강도가 7 이상이면 아래에 코멘트가 추가됩니다.

```
[대응 코멘트]
<지금 해볼 수 있는 대응 방법 1~2문장>
```

| 항목        | 설명                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| 주 감정     | 가장 두드러진 감정                                                     |
| 부 감정     | 함께 나타나는 감정                                                     |
| 합성 감정   | 주 감정 + 부 감정 조합에 해당하는 플루치크의 합성 감정 (텍스트만 표시) |
| 강도        | 1(아주 희미함) ~ 9(통제하기 힘들 정도로 강렬함)                        |
| 신뢰도      | 주 감정 판독에 대해 모델이 스스로 매긴 확신도 (보정된 확률이 아님)     |
| 대응 코멘트 | 부정적인 감정이 강도 7 이상일 때만 표시                                |

## 감정 목록

기본 감정 8가지: 기쁨(JOY), 신뢰(TRUST), 공포(FEAR), 놀람(SURPRISE), 슬픔(SADNESS), 혐오(DISGUST), 분노(ANGER), 기대(ANTICIPATION)

각 기본 감정은 플루치크 감정의 바퀴의 강도 3단계(약함 - 기본 - 강함)를 함께 포함합니다. 예를 들어 존경·감탄은 신뢰, 지루함은 혐오, 짜증은 분노로 판독합니다.

감정 정의에는 서로 헷갈리기 쉬운 감정과 구분하는 기준도 함께 적혀 있습니다. 부정적인 문장은 바로 슬픔으로 고르지 않고, 탓하는 대상이 있는지(자기 자신 포함, 분노), 걱정·고민·스트레스처럼 앞으로가 불확실한지(공포), 이미 잃고 체념했는지(슬픔) 순서로 판단합니다. 사람·작품에 대한 감탄·찬사는 신뢰로, 상대에게 바라는 인사·소망(잘 자, 좋은 꿈 꿔)은 기대로 봅니다.

| 감정 | 약함 - 기본 - 강함 |
| --- | --- |
| 기쁨 | 평안 - 기쁨 - 황홀 |
| 신뢰 | 승인 - 신뢰 - 존경 |
| 공포 | 불안 - 공포 - 극심한 공포 |
| 놀람 | 신경쓰임 - 놀람 - 깜짝 놀람 |
| 슬픔 | 수심 - 슬픔 - 비탄 |
| 혐오 | 지루함 - 혐오 - 증오 |
| 분노 | 짜증 - 분노 - 격노 |
| 기대 | 관심 - 기대 - 경계 |

합성 감정 28가지 (두 기본 감정의 조합, 순서 무관):

| 구분       | 합성 감정                                                                                                                                                  |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1차 (인접) | 사랑(기쁨+신뢰), 순종(신뢰+공포), 경외(공포+놀람), 반감(놀람+슬픔), 자책(슬픔+혐오), 경멸(혐오+분노), 공격성(분노+기대), 낙관(기대+기쁨)                   |
| 2차        | 죄책감(기쁨+공포), 절망(공포+슬픔), 시기(슬픔+분노), 자부심(분노+기쁨), 호기심(신뢰+놀람), 불신(놀람+혐오), 냉소(혐오+기대), 희망(기대+신뢰)               |
| 3차        | 큰 기쁨(기쁨+놀람), 격분(놀람+분노), 우월감(분노+신뢰), 감상적임(신뢰+슬픔), 비관(슬픔+기대), 염려(기대+공포), 수치심(공포+혐오), 불건전한 흥미(혐오+기쁨) |
| 반대 감정  | 씁쓸함(기쁨+슬픔), 애증(신뢰+혐오), 얼어붙음(공포+분노), 혼란스러움(놀람+기대)                                                                             |

각 감정의 판단 기준은 `main.py`의 `EMOTION_CRITERIA`에, 코멘트 대상 감정과 강도 기준은 `NEGATIVE_EMOTIONS`, `ADVICE_MIN_INTENSITY`에, 합성 감정 조합은 `COMPOSITE_EMOTIONS`에 정의되어 있습니다.

## 설치

Python 3 가상환경을 권장합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

프로젝트 루트에 `.env` 파일을 만들고 API 키를 넣습니다.

```
OPENAI_API_KEY=your-api-key
```

## 실행

```bash
python main.py
```

`입력:` 프롬프트에 분석할 문장을 입력하면 결과가 출력됩니다.

> 감정 이미지는 iTerm2 인라인 이미지 프로토콜로 출력되므로 iTerm2(또는 이 프로토콜을 지원하는 터미널)에서만 보입니다. 다른 터미널에서는 이미지 없이 텍스트만 정상 표시됩니다.

## 실행 파일 빌드

PyInstaller로 단일 실행 파일을 만들 수 있습니다. `main.spec`에 `emotions/` 폴더가 포함되도록 설정되어 있습니다.

```bash
pip install pyinstaller
pyinstaller main.spec
./dist/main
```

실행 파일도 `OPENAI_API_KEY`가 필요하므로, 실행하는 위치에 `.env`를 두거나 환경 변수로 설정하세요.

감성사전은 재배포 금지 자료라 실행 파일에 넣지 않습니다. 실행 파일과 같은 폴더에 `data/sentiment.json`을 두면 감성사전 근거 단어를 함께 써서 판독하고, 없으면 감성사전 없이 판독합니다. 감성사전 단어를 찾는 형태소 분석 모델(kiwipiepy_model, 약 100MB)이 들어가므로 실행 파일은 130MB 정도입니다.

```
dist/
├── main
└── data/
    └── sentiment.json
```

## 평가

외부 감정 말뭉치에서 뽑은 정답 라벨로 판독 방식과 모델을 비교합니다. 앱 실행에는 필요 없고, 평가할 때만 씁니다.

### 평가 데이터

| 감정 | 정답 라벨 출처 | 비고 |
| --- | --- | --- |
| 기쁨·공포·슬픔·분노 | [AI Hub 감성 대화 말뭉치](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=86)의 첫 사람 문장 | 1인칭으로 상황과 감정을 말하는 문장이라 일기 형식에 가장 가깝습니다. 대분류 '불안'을 공포로 봅니다. 상처·당황은 제외합니다. |
| 신뢰·기대·놀람·혐오 | 국립국어원 감정 분석 말뭉치 (AI말평 2024, train·dev) | 플루치크 8감정 라벨입니다. 감정이 하나만 붙은 문장만 씁니다. SNS 글입니다. |

- 평가 세트 `data/eval_external.json`: 감정당 150문장, 총 1,200문장. 최종 수치를 낼 때 한 번만 씁니다.
- 개발용 세트 `data/eval_dev.json`: 평가 세트 문장을 빼고 감정당 40문장, 총 320문장. 프롬프트를 고칠 때 효과를 먼저 확인하는 데 씁니다.

원본 말뭉치는 재배포가 금지되어 있어 저장소에 없습니다. 각 기관에서 받아 아래 위치에 두고 세트를 만듭니다.

```
한국어 감정 정보가 포함된 연속적 대화 데이터셋/감성대화말뭉치(최종데이터)_Training.xlsx
NIKL_EA_2024/nikluge-감정분석-2024-{train,dev}.jsonl
```

```bash
pip install openpyxl
python build_eval_set.py                                     # 평가 세트
python build_eval_set.py --per-emotion 40 --seed 1 \
    --exclude data/eval_external.json --output data/eval_dev.json   # 개발용 세트
```

### 비교 실행

`compare_sentiment.py`는 같은 문장을 여러 방식(LLM 단독, 감성사전 참고, Jev 1차 분류 참고)과 모델로 판독해 정답률, 감정별 정답률, 비용, 지연을 비교합니다. 감성사전 방식은 `data/sentiment.json`이 필요하고, Jev 방식은 `.env`에 `TYPESAFE_API_KEY`가 필요합니다.

```bash
pip install openpyxl kiwipiepy typesafe-sdk
python compare_sentiment.py --eval data/eval_external.json --models gpt-4.1 \
    --variants "3 근거단어" --save results/run.jsonl
```

`--save`를 주면 호출이 끝날 때마다 결과를 JSONL에 바로 저장합니다. 저장 항목은 정답 라벨, 판독 결과, Jev 확률, 토큰, 비용, 지연, LLM에 넘긴 참고 자료입니다. 실패한 호출은 3번까지 다시 시도하고, 같은 명령을 다시 실행하면 끝난 호출은 건너뛰고 나머지만 돌립니다. 실행 설정(프롬프트, 감정 정의, 가격표, 평가 파일 해시)은 `results/run.meta.json`에 남습니다.

### 결과 (2026-11-17, 평가 세트 1,200문장, gpt-4.1)

| 방식 | 감정 정의 | 주 감정 정답률 | Macro F1 | 1,000회당 비용 |
| --- | --- | --- | --- | --- |
| Jev 1차 분류 + 감성사전 (근거단어) | 이전 정의 | 53% | 0.513 | $2.60 |
| 감성사전만 (근거단어) | 이전 정의 | 55% | 0.534 | $2.39 |
| 감성사전만 (근거단어) | 플루치크 강도 3단계 | 59% | 0.581 | $2.58 |
| 감성사전만 (근거단어) | 강도 3단계 + 혼동 감정 기준 보강 | **63%** | **0.632** | $3.52 |

- 감정 정의에 강도 3단계를 넣자 신뢰(19% → 39%)와 혐오(59% → 76%)가 크게 올랐습니다. 이전 정의와 비교한 McNemar 검정 결과는 p < 0.001입니다.
- 강도 3단계 정의는 분노(29%)와 공포(46%) 문장을 슬픔으로 판독하는 경우가 많았습니다. 개발용 세트에서 틀린 문장을 보고 헷갈리는 감정의 기준(자책 → 분노, 고민·스트레스 → 공포, 찬사 → 신뢰, 바람 → 기대)을 보강하자 신뢰 79%, 공포 67%, 분노 41%로 올랐습니다. 강도 3단계 정의와 비교한 McNemar 검정 결과는 p = 0.003입니다.
- 대신 슬픔(87% → 71%)과 혐오(76% → 55%)는 내려갔고, 혐오 문장의 27%를 분노로 판독합니다. 분노는 여전히 가장 약한 감정입니다(F1 0.37).
- 보강으로 프롬프트가 1,032토큰에서 약 1,720토큰으로 길어져 비용이 36% 늘었습니다. 평균 응답 시간은 2.0초입니다.
- 부 감정, 강도, 대응 코멘트 여부는 정답 라벨이 없어 채점하지 않았습니다.

## 파일 구성

```
main.py              # 감정 분석 CLI (신조어 탐지, GPT 호출, 결과 출력)
main.spec            # PyInstaller 빌드 설정
emotions/            # 감정별 해양이 이미지 (<한글 감정 이름>.png, 예: 기쁨.png)
data/neologisms.json # 신조어별 예시 대화 사전
build_neologisms.py  # 신조어 사전 생성 스크립트
build_eval_set.py    # 외부 말뭉치에서 평가·개발용 세트 생성
compare_sentiment.py # 판독 방식·모델 비교 실험 (정답률, 비용, 결과 저장)
build_sentiment.py   # 감성사전.xlsx → data/sentiment.json 변환
base.ts              # 초기 설계용 TypeScript 스키마 (27가지 감정 버전, 현재 미사용)
```

저장소에 없는 파일(재배포 금지, `.gitignore`): 원본 말뭉치 폴더, `감성사전.xlsx`, `data/sentiment.json`, `data/eval_external.json`, `data/eval_dev.json`, `results/`.
