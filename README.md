# jev

입력한 문장에서 감정을 판독하는 CLI 도구입니다. OpenAI API(`gpt-4.1`, Structured Outputs)로 [플루치크(Plutchik)의 감정 이론](https://namu.wiki/w/%EB%A1%9C%EB%B2%84%ED%8A%B8%20%ED%94%8C%EB%A3%A8%EC%B9%98%ED%81%AC)에 따라 8가지 기본 감정 중 주 감정과 부 감정, 강도, 신뢰도를 분석하고, 감정별 테루테루보즈 이미지와 함께 결과를 보여줍니다. 주 감정과 부 감정의 조합으로 만들어지는 합성 감정은 이미지 없이 텍스트로 보여줍니다. 부정적인 감정이 강하게 나타나면 대응 방법에 대한 코멘트도 함께 보여줍니다.

## 신조어 처리

입력 문장에 신조어가 있으면 [KoCulture-Dialogues](https://huggingface.co/datasets/huggingface-KREW/KoCulture-Dialogues) 데이터셋에서 그 신조어가 쓰인 예시 대화를 찾아, 참고 자료로 함께 모델에 넘깁니다. 모델이 신조어의 뜻을 문맥으로 파악해 감정을 더 정확히 판독하도록 하기 위한 것입니다. 문장 자체를 표준어로 바꾸지는 않습니다.

- 사전: `data/neologisms.json` (신조어 354개, 단어당 예시 대화 최대 2개)
- 탐지: 입력 문장에 신조어가 그대로 들어 있는지 확인합니다. 한 글자 신조어(`갓`, `각` 등)는 일반 단어와 구분이 안 돼 제외합니다.
- 한계: `사이다`, `고구마`처럼 일반 단어와 같은 신조어는 원래 뜻으로 쓰여도 신조어로 잡힙니다. `~에 진심인 편`처럼 틀 형태인 신조어는 탐지되지 않습니다.

신조어가 탐지되면 모델에는 입력 문장 대신 아래 형식의 텍스트가 user 메시지로 넘어갑니다 (`main.py`의 `build_state`). 신조어가 없으면 입력 문장만 그대로 넘어갑니다.

```
[분석할 문장]
요즘 갓생 사는 게 내 추구미임

[참고: 위 문장에 쓰인 신조어의 용례. 감정 판단 대상이 아니며 신조어의 뜻을 이해하는 데만 사용]
- 추구미: "<예시 대화 1 질문>" / "<예시 대화 1 답변>"
- 추구미: "<예시 대화 2 질문>" / "<예시 대화 2 답변>"
- 갓생: "<예시 대화 1 질문>" / "<예시 대화 1 답변>"
- 갓생: "<예시 대화 2 질문>" / "<예시 대화 2 답변>"
```

예시 대화에도 감정이 담겨 있어 판독에 영향을 줄 수 있으므로, 감정 판단 대상이 아니라는 안내를 함께 넣습니다.

사전을 다시 만들려면:

```bash
pip install pyarrow
python build_neologisms.py
```

## 출력 예시

```
입력: 오랜만에 옛날 사진을 보니까 그때가 그립다

[분석 완료]
<슬픔 이미지>
주 감정: 슬픔
<기쁨 이미지>
부 감정: 기쁨
합성 감정: 씁쓸함 (슬픔 + 기쁨)
강도:   🟧🟧🟧🟧🟧🟧⬜⬜⬜ (6/9)
신뢰도: 87%
```

주 감정이 부정적인 감정(공포, 슬픔, 혐오, 분노)이고 강도가 7 이상이면 아래에 코멘트가 추가됩니다.

```
[대응 코멘트]
<지금 해볼 수 있는 대응 방법 1~2문장>
```

| 항목        | 설명                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| 주 감정     | 가장 두드러진 감정                                                     |
| 부 감정     | 함께 나타나는 감정                                                     |
| 합성 감정   | 주 감정 + 부 감정 조합에 해당하는 플루치크의 합성 감정 (텍스트만 표시) |
| 강도        | 1(아주 희미함) ~ 9(통제하기 힘들 정도로 강렬함)                        |
| 신뢰도      | 주 감정 판독에 대해 모델이 스스로 매긴 확신도 (보정된 확률이 아님)     |
| 대응 코멘트 | 부정적인 감정이 강도 7 이상일 때만 표시                                |

## 감정 목록

기본 감정 8가지: 기쁨(JOY), 신뢰(TRUST), 공포(FEAR), 놀람(SURPRISE), 슬픔(SADNESS), 혐오(DISGUST), 분노(ANGER), 기대(ANTICIPATION)

각 기본 감정은 플루치크 감정의 바퀴의 강도 3단계(약함 - 기본 - 강함)를 함께 포함합니다. 예를 들어 존경·감탄은 신뢰, 지루함은 혐오, 짜증은 분노로 판독합니다.

| 감정 | 약함 - 기본 - 강함 |
| --- | --- |
| 기쁨 | 평안 - 기쁨 - 황홀 |
| 신뢰 | 승인 - 신뢰 - 존경 |
| 공포 | 불안 - 공포 - 극심한 공포 |
| 놀람 | 신경쓰임 - 놀람 - 깜짝 놀람 |
| 슬픔 | 수심 - 슬픔 - 비탄 |
| 혐오 | 지루함 - 혐오 - 증오 |
| 분노 | 짜증 - 분노 - 격노 |
| 기대 | 관심 - 기대 - 경계 |

합성 감정 28가지 (두 기본 감정의 조합, 순서 무관):

| 구분       | 합성 감정                                                                                                                                                  |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1차 (인접) | 사랑(기쁨+신뢰), 순종(신뢰+공포), 경외(공포+놀람), 반감(놀람+슬픔), 자책(슬픔+혐오), 경멸(혐오+분노), 공격성(분노+기대), 낙관(기대+기쁨)                   |
| 2차        | 죄책감(기쁨+공포), 절망(공포+슬픔), 시기(슬픔+분노), 자부심(분노+기쁨), 호기심(신뢰+놀람), 불신(놀람+혐오), 냉소(혐오+기대), 희망(기대+신뢰)               |
| 3차        | 큰 기쁨(기쁨+놀람), 격분(놀람+분노), 우월감(분노+신뢰), 감상적임(신뢰+슬픔), 비관(슬픔+기대), 염려(기대+공포), 수치심(공포+혐오), 불건전한 흥미(혐오+기쁨) |
| 반대 감정  | 씁쓸함(기쁨+슬픔), 애증(신뢰+혐오), 얼어붙음(공포+분노), 혼란스러움(놀람+기대)                                                                             |

각 감정의 판단 기준은 `main.py`의 `EMOTION_CRITERIA`에, 코멘트 대상 감정과 강도 기준은 `NEGATIVE_EMOTIONS`, `ADVICE_MIN_INTENSITY`에, 합성 감정 조합은 `COMPOSITE_EMOTIONS`에 정의되어 있습니다.

## 설치

Python 3 가상환경을 권장합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

프로젝트 루트에 `.env` 파일을 만들고 API 키를 넣습니다.

```
OPENAI_API_KEY=your-api-key
```

## 실행

```bash
python main.py
```

`입력:` 프롬프트에 분석할 문장을 입력하면 결과가 출력됩니다.

> 감정 이미지는 iTerm2 인라인 이미지 프로토콜로 출력되므로 iTerm2(또는 이 프로토콜을 지원하는 터미널)에서만 보입니다. 다른 터미널에서는 이미지 없이 텍스트만 정상 표시됩니다.

## 실행 파일 빌드

PyInstaller로 단일 실행 파일을 만들 수 있습니다. `main.spec`에 `emotions/` 폴더가 포함되도록 설정되어 있습니다.

```bash
pip install pyinstaller
pyinstaller main.spec
./dist/main
```

실행 파일도 `OPENAI_API_KEY`가 필요하므로, 실행하는 위치에 `.env`를 두거나 환경 변수로 설정하세요.

## 파일 구성

```
main.py              # 감정 분석 CLI (신조어 탐지, GPT 호출, 결과 출력)
main.spec            # PyInstaller 빌드 설정
emotions/            # 감정별 테루테루보즈 이미지 (<한글 감정 이름>.png, 예: 기쁨.png)
data/neologisms.json # 신조어별 예시 대화 사전
build_neologisms.py  # 신조어 사전 생성 스크립트
base.ts              # 초기 설계용 TypeScript 스키마 (27가지 감정 버전, 현재 미사용)
```
